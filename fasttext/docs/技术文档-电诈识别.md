# 技术文档 · 中文电诈识别

## 1. 任务与范围

输入一段中文文本（短信、客服对话、案件描述），输出 10 个类别中概率最高的一类，并给出“是否诈骗”的判定。

- 输出空间：`无风险` + 9 类诈骗手法（与反诈大数据平台分类标准一致）
- 适用域：中文电诈短信 / 对话 / 案情简述
- 不适用：招聘岗位帖（实测无区分能力，见评估文档第 5 节）

**标签体系说明**：本语料的 10 类中**没有独立的「刷单返利类」**，含"刷单"字样的 28,219 条样本里
83.9% 被标为「虚假网络投资理财类」、14.9% 为「无风险」（多为反诈提醒）。因此刷单类诈骗会被判成投资理财，
这是标签体系决定的结果，不是模型错误。

**切分沿用源表自带的 `split` 列**，该切分按 `source`（五种生成方式）全维度分层，
五种来源在三集中的占比均为 17%~23%，且 `group`（案件级）不跨集。

数据集目录 `data/zh_data_process/` 与旧数据集命名规范一致：

```

```

## 3. 预处理

中文按**逐字切分**（每个汉字之间加空格），不依赖分词器：
短信与对话里大量口语、错别字、拼音缩写，词级切分反而引入词典外噪声。

```
文本 → 空白归一 → 去掉空格 → 逐字加空格 → "__label__{id} {tokens}"
```

## 4. 模型

fastText 监督多分类（`train_supervised`）：

```python
dim=50, epoch=25, lr=0.5, wordNgrams=2,
bucket=200000, minCount=2, loss="softmax", ws=5, neg=5, seed=20261021
```

- 训练耗时 40.1 秒（246,403 条，32 线程）
- 模型体积 38.9 MB
- 训练代码：`fasttext/experiments/zh_fraud/train_multiclass.py`

## 5. 训练流程

```bash
# 1) 原始语料 -> 标准数据集目录
python -X utf8 fasttext/experiments/zh_fraud/build_dataset_dir.py

# 2) 训练 + 评估（读 data/zh_data_process，写 fasttext/models_zh/）
python -X utf8 fasttext/experiments/zh_fraud/train_multiclass.py

# 3) 概率校准（可选）
python -X utf8 fasttext/experiments/zh_fraud/calibrate.py
```
