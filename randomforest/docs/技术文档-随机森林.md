# 技术文档 · 中文电诈识别（随机森林 / XGBoost）

## 1. 任务

与 fastText 链路同任务、同数据、同标签：中文电诈文本 **10 类分类**（无风险 + 9 类手法），
输出概率最高的类别。

本链路与 fastText 的差别在于**特征表示与模型**：
jieba 分词 + TF-IDF 稀疏特征 + XGBoost 梯度提升树，而不是 fastText 的字级嵌入。

## 2. 数据

与 fastText 共用 `data/zh_data_process/`，**不复制、不另存**：

| 项目 | 数值 |
|---|---|
| 训练 / 验证 / 测试 | 246,403 / 53,152 / 53,281 |
| 类别数 | 10（`class.txt` 行号即标签，0=无风险） |
| 切分 | 源表官方 split，按 `source` 分层，`group` 不跨集 |
| 重复率 | 0% |

## 3. 预处理

```
文本 → jieba 分词 → 空格连接 → TF-IDF（token_pattern=\S+，去停用词）
```

- 停用词：`data/zh_data_process/stopwords.txt`
- TF-IDF 词表：**79,948 维**，非零元素 980 万
- 产物：`randomforest/processing/{train,dev,test}.csv`（`title,label,label_zh,words`）

> 分词耗时：246k 条约 136 秒。

## 4. 模型

XGBoost `multi:softprob`，300 棵树分 10 轮训练（每轮 30 棵，便于观察 dev 曲线）：

| 参数 | 值 |
|---|---|
| max_depth | 6 |
| eta | 0.3 |
| subsample | 0.8（行采样，近似 RF 的 bagging） |
| colsample_bytree | 0.3（列采样，近似 RF 的特征子集） |
| tree_method | hist |
| device | `cuda`（GPU）/ `cpu` 可切换 |

**类别加权**：按 `总样本 / (类别数 × 该类样本数)` 给样本权重，缓解长尾
（军警购物权重 16.6，无风险仅 0.255）。

- 训练耗时：**181 秒**（RTX 4060 Laptop 8GB，CUDA 13.3）
- 产物：`models/rf_model.json` + `models/tfidf_vectorizer.pkl`

## 5. 目录结构

```
randomforest/
  config.py              路径与超参（唯一入口）
  data_processing.py     txt -> jieba -> CSV
  train.py               TF-IDF + XGBoost 训练
  evaluate.py            混淆矩阵 / 逐类指标 / metrics.json
  predict.py             命令行推理
  api.py                 FastAPI 服务
  requirements.txt       依赖
  processing/            分词中间产物（不入库）
  models/                模型与指标（不入库）
  docs/                  技术 / 评估 / API 文档
```

## 6. 复现

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r randomforest/requirements.txt

# 1) 分词（约 3 分钟）
.venv/Scripts/python.exe -X utf8 randomforest/data_processing.py

# 2) 训练（GPU 约 3 分钟；无 GPU 用 RF_DEVICE=cpu）
RF_DEVICE=cuda .venv/Scripts/python.exe -X utf8 randomforest/train.py

# 3) 评估
.venv/Scripts/python.exe -X utf8 randomforest/evaluate.py

# 4) 起服务
.venv/Scripts/python.exe -X utf8 randomforest/api.py
```

环境变量：`RF_DEVICE`（cpu/cuda）、`RF_ROUNDS`（树数，默认 300）、`RF_CHUNK`（每轮树数）、`PORT`（服务端口）。

## 7. 与 fastText 链路的关系

两条链路**并存**，共用同一份数据和标签体系，便于对比选型：

| | fastText | 随机森林（本链路） |
|---|---|---|
| 特征 | 字级 n-gram 嵌入 | jieba 词 + TF-IDF |
| 模型 | 线性 softmax | 梯度提升树 |
| 训练时长 | 40 秒（CPU） | 181 秒（GPU） |
| 模型体积 | 38.9 MB | 5.3 MB（json）+ 0.6 MB（向量器） |

指标对比见 [评估文档](评估文档-随机森林.md)。
